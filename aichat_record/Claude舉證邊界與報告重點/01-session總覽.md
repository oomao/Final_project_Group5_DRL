## 這個階段做了什麼

本 session 為口試／報告防禦,把「記憶有效性」主結論的弱點主動整理成可防禦材料,並把整份報告濃縮成一頁重點。產出兩組獨立文件,**皆不動論文與口白本體**。

### 第一部分：問題與討論——舉證邊界三問（`問題與討論/`）

由使用者三點筆記收斂,框成由外而內的三道「舉證邊界」：

- **01 範圍（scope）**：四環境太簡單,沒給記憶完整發揮的 headroom。關鍵反轉論點——簡單任務「低估」而非高估記憶價值（6.1：一次性塑形越接近最優、記憶 headroom 越小；Acrobot −83.21→−82.92≈0、CartPole 187.64→334.44 大）→ null/負向應讀成保守下界。
- **02 歸因（attribution）**：「記憶好/壞」太結果導向。記憶變因本身有乾淨對照（B3 vs B3-no-memory,LL p=0.0317）,但「因為密集才有害」沒控制（密集環境僅 1 個、密度與塑形空間混淆、4 個記憶效應僅 1 個顯著、n=5）→ 全文用「關聯」非「導致」。
- **03 機制（mechanism）**：Why 對應太多方向、無法收斂。現象穩（Part 2 三變體重現）、機制欠定（候選分「哪條軸預測」與「靠什麼過程」兩族,四環境無法分離）→ 不硬收斂,每條岔路掛一個實驗。
- 另含 `README.md` 索引（速查表 ＋ 共用未來工作矩陣 ＋ 防禦骨架）。

決策歷程：先合成一檔 → 依使用者要求**拆三檔 ＋ README 索引**（`NN-` 從 01 起,README 不佔序號）。

### 第二部分：報告重點整理（`報告重點整理.md`,頂層）

整份論文「一頁懂」的 Markdown 重點大綱：動機 → 方法（三模組）→ 設定（四環境/六條件/120 次/統計）→ 主要結果（稀疏贏、密集記憶有害、變異指紋、Part 2 重現）→ 結論 → 限制與舉證邊界 → 可證偽預測；末附「搭配圖檔對應表」（哪個區塊配哪張 fig,之後可做成視覺資訊圖表）。
選項取捨：使用者選「整份報告重點（一頁懂）」＋「Markdown 重點大綱」（未選 HTML 視覺版）。
