### 7 步閉環 per iteration

```
1. Hermes memory.top_k_by_fitness(k=5)              → priors
2. LLMRewardClient.generate(memory=priors)           → reward_src
3. diff_rewards(prev_src, new_src)                   → diff(iter 1 跳過)
4. apply_policy(prev_buffer, decide_policy(diff))    → KEEP/DECAY/CLEAR
5. train(config, pre_loaded_buffer=buf, pre_resolved_reward=(src, fn))
6. evaluate_on_env_native(run_dir, n=100)            → env_native_mean
7. memory.write(MemoryEntry)、buffer.save(buffer.npz)
```

每 iter 跑完寫 `iter_<II>/{config, episodes, model, reward_fn, llm_attempts, buffer}`。整個 seed run 寫一份 `summary.json`(iter-level fitness 序列)。

### Run 目錄階層(對齊 `experiments-protocol` R6)

```
runs/<exp_name>/<condition_id>/seed_<NN>/
├── summary.json
├── memory.sqlite                ← per-condition 獨立(避免污染)
└── iter_<II>/
    ├── config.json
    ├── episodes.jsonl
    ├── reward_fn.py
    ├── model_final.pt
    ├── llm_attempts.jsonl
    └── buffer.npz                ← 給下個 iter 用
```

### train.py 的小重構

新增兩個 optional 參數,backward-compat 預設 None:
- `pre_loaded_buffer: ReplayBuffer | None`:closed_loop 把上 iter 的 buffer 注入
- `pre_resolved_reward: tuple[str, Callable] | None`:closed_loop 自己負責 Gemma 生成,告訴 train.py 「reward 已準備好,直接用」

並讓 train.py 每次跑完都把 `agent.buffer.save(run_dir/buffer.npz)` 自動寫掉(~7.6 MB compressed,可接受)。

### 統計工具:`tools/compare_conditions.py`

```bash
python tools/compare_conditions.py --exp final --conditions B0,B1,B2,B3,B3-no-memory,B3-no-AST
```

對每對 condition:
- `scipy.stats.mannwhitneyu`(雙尾 α=0.05)
- 5000-bootstrap 95% CI(固定 seed=12345)
- **三條件 Win 判定**(p<0.05 AND ≥10% 平均差 AND CI 不重疊)三者齊全才算 win

產出:
- `reports/<exp>/comparison_report.md`(per-condition 表 + 配對矩陣 + outliers + compute)
- `reports/<exp>/figures/training_curves.png`(300 dpi,訓練曲線 + 95% CI shaded)
- `reports/<exp>/figures/iteration_fitness.png`(iter-level fitness 折線)

## Pilot 結果(3 iter × seed 42,52.5 分鐘)

| Iter | Priors | AST diff | Buffer action | env_native_mean | Success | Crash |
|---|---|---|---|---|---|---|
| 1 | `[]` | — | — | 181.33 | 65% | 22% |
| 2 | `[1]` | STRUCTURAL_DIFF(sim 0.71) | **DECAY** | 90.35 | 12% | 12% |
| 3 | `[1, 2]` | TOTAL_REWRITE(sim 0.56) | **CLEAR** | 168.54 | 25% | **2%** |

### 機制驗證(全綠)

- ✅ `memory_priors_used=[1]` 確認 iter 2 收到 iter 1 寫的 entry
- ✅ AST 相似度 0.71 剛好過 0.7 門檻 → STRUCTURAL_DIFF;0.56 → TOTAL_REWRITE
- ✅ Buffer action 確實依 diff 決定(`summary.json[1].buffer_action == "decay"`)
- ✅ 所有 artifact 跨 iter 正確存放,buffer.npz 可被下 iter load

### 實證信號(n=1 太吵)

env_native_mean 非單調(181 → 90 → 168)。唯一單調是 crash rate(22 → 12 → **2%**),跟先前「Gemma trade reward for safety」觀察一致。

**不能用 n=1 下結論**。`evaluation-criteria` spec 規定 5 seed + Mann-Whitney + bootstrap CI 才能 claim。

跑 `python tools/compare_conditions.py --exp pilot --conditions B3-pilot` 在 1-condition pilot 上,正確產出 summary table + 圖檔(`training_curves.png` 144 KB、`iteration_fitness.png` 134 KB)。**工具就緒,等實驗週填數據**。

## 為什麼沒跑完整 6 condition × 5 seed
