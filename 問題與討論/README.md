# 問題與討論:舉證邊界三問(索引)

> Hermes-DQN 對「記憶有效性」這條主結論,*主動攤開*的三道舉證邊界,供口試／研討會質詢時誠實防禦用。由外而內——**範圍 → 歸因 → 機制**。
> **核心一句**:我們交付的是「一個穩的現象 ＋ 一份可證偽的菜單」,不是「一個被證明的因果」。
> **對應論文**:6.1(記憶貢獻隨單次塑形品質遞減)、6.2(密集獎勵記憶有害假設)、6.3(變異指紋)、6.4(限制)、6.5(可證偽預測)。

## 三問(各自一檔)

1. [01-範圍](01-範圍.md):四個環境太簡單,沒給記憶完整發揮的 headroom
2. [02-歸因](02-歸因.md):記憶好/壞太結果導向,缺密度的控制變因
3. [03-機制](03-機制.md):Why 對應太多方向、無法收斂

## 速查(一行版)

| # | 質詢(老師會問) | 一句話回應 |
|---|---|---|
| 1 範圍 | 四個環境太簡單,能完整呈現記憶有效性嗎? | 不能,外部效度限制——但它「低估」而非高估記憶價值:6.1 顯示一次性塑形越接近最優、記憶 headroom 越小(Acrobot −83.21→−82.92≈0;CartPole 187.64→334.44 大),故 null/負向應讀成保守下界。選簡單環境是刻意取捨(受控階乘 6×4×多種子×3變體、乾淨密度軸、可解讀 seed_43)。下一步:MuJoCo/Atari ＋ 拉長迭代輪數。 |
| 2 歸因 | 「記憶好/壞」太結果導向,有控制變因嗎? | 「記憶」變因有乾淨對照(B3 vs B3-no-memory,只差記憶,LL p=0.0317);但「因為密集才有害」沒控制——密集環境只 1 個、密度與塑形空間混淆、4 個記憶效應只 1 個顯著(其餘稀疏 p=0.22/0.14/0.75 n.s.)、n=5 僅夠抓大效應。故全文寫「關聯」非「導致」。要舉證:LunarLanderContinuous 拆混淆 ＋ n→10/20。 |
| 3 機制 | Why 對應太多方向、無法收斂,哪個才對? | 現象穩(密集落後、稀疏領先,Part 2 三變體重現),機制欠定:候選分兩族——哪條軸預測(密度? 塑形豐富度? 複雜度×密度)＋ 靠什麼過程(勢能漂移 Ng[13]? 疊塑形項打架? 錨點強弱? Gemma 抽樣?),四環境無法分離。故只把 potential-based 當 working hypothesis、其餘列並存、seed_43 明說軼事,不硬收斂。每條岔路掛實驗:LunarLanderContinuous、formal verifier、換 LLM 重跑、二維分類。 |

## 防禦時的講法(共用骨架)

先講穩的(**WHAT**:效果＋Part 2 跨變體重現)→ 認邊界(**不灌水**,甚至點明第 1 題是保守下界)→ 指名能跨過邊界的**那一個實驗**。一句收尾:**「我們交付的是一個穩的現象 ＋ 一份可證偽的菜單,不是一個被證明的因果。」**
