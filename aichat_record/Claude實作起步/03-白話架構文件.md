## 設計理念

### 單一主比喻貫穿全文

選了 **籃球隊**(對應 README 已有的「教練系統 / 球員管理」描述):

- 教練 = Hermes Agent(調度)
- 教練的腦 = Gemma 4 31B(寫戰術細節)
- 球員 = DQN Agent(在球場上跑)
- 球場 = Gymnasium LunarLander-v3
- 戰術手冊 = Reward Function(LLM 寫的 Python code)
- 球員的肌肉記憶 = Replay Buffer
- 教練的筆記本(4 層) = Hermes 記憶系統
- 戰術手冊比對 = AST 管理器
- 肌肉記憶處理 = Buffer 管理器
- 比賽成績單 = Fitness Evaluator

子比喻(只在環境設置那段加):

- **「蓋一座球員訓練場」** ── 對應開發環境(球場 / 物理引擎 / 球員身體 / 計分板)
- **「蓋房子要先蓋承重牆」** ── 對應 5 份 change 的實作順序

### 結構(13 個章節)

```

❗ 為什麼要做(3 痛點 + 1 衍生痛點)
```

## 三個我特別在意的設計

### 1. Mermaid + ASCII fallback

每個 Mermaid 圖底下都有純文字版,如果讀者的 markdown viewer 不支援 Mermaid 也看得懂:

```
[教練系統 + 4 層記憶] ──prompt──> [Gemma 大腦] ──寫出 reward──>
                                                              ↓
       ┌─寫回記憶─ [Fitness] <── [DQN 球員 + 球場] <── [Buffer 管理] <── [AST 比對]
       │
       └──> 下一輪用更厚的筆記本想戰術
```

### 2. 術語翻譯表

```
reward function       → 得分規則
replay buffer         → 球員的肌肉記憶
catastrophic forgetting → 災難性遺忘
AST                   → 程式碼結構樹
fitness               → 成績單
convergence           → 學會了
ε-greedy              → 探索 vs 經驗的拿捏
Q-Network             → 球員的腦
target network        → 穩定參考版
```

口試時隊員看著這張表就能即時翻譯。

### 3. 口試版收尾

> **讓 AI 教練自己翻筆記想戰術、叫 AI 大腦寫程式、給 AI 球員照著練,
> 還會聰明處理球員的肌肉記憶 ── 這就是 Hermes-DQN。**

這句話刻意背得起來,口試開場可以直接念。

## 加入的「實作建議」段(後續補充)

### 五份 OpenSpec change 的順序

| # | Change | 適合誰 | 工時 |
|---|---|---|---|
| 1 | bootstrap-dqn-baseline | 任一人 | 1 天(已完成) |
| 2 | gemma-reward-generator | 寫 API 的人 | 2-3 天 |
| 3 | hermes-memory-layer | 熟 SQLite 的人 | 3-5 天 |
| 4 | ast-buffer-manager | 熟 Python ast 的人 | 3-4 天 |
| 5 | closed-loop-fitness | 整合 / 寫作能力強的 | 持續到 demo |

### 為什麼這個順序

每一份 change 結束都是**獨立可發表的命題**,不必全部做完才有東西報告。

### 接縫(4 個 interface)

```python
# 接縫 1:reward_fn 簽章 — 已定
def reward_fn(obs, action, next_obs, env_reward, terminated, truncated, info) -> float

# 接縫 2:Gemma client
class LLMRewardClient:
    def generate(self, task_desc: str, memory: list["MemoryEntry"]) -> str

# 接縫 3:記憶條目
@dataclass
class MemoryEntry:
    reward_code: str
    fitness: FitnessReport
    notes: str

# 接縫 4:Buffer 動作
class BufferAction(Enum):
    KEEP = "keep"
    DECAY = "decay"
    CLEAR = "clear"
```
